# Simple Interest Calculator

A Bash calculator that computes simple interest from a principal amount, annual interest rate, and time period in years.

## Formula

`Simple interest = (principal × annual interest rate × time in years) / 100`

Enter the rate as a percentage: enter `5` for 5%.

## Run

```bash
bash simple-interest.sh
```

When prompted, enter the principal, rate of interest, and time period. Decimal inputs are supported. Values must be non-negative numbers.

## Example

```text
Enter the principal amount: 1000
Enter the annual rate of interest (%): 5
Enter the time period in years: 2
The simple interest is: 100.00
```
