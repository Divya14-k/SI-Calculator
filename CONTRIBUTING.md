# Contributing

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## Report an issue

Open an issue describing the problem, steps to reproduce it, expected behavior, and actual behavior. For calculator bugs, include the principal, interest rate, and time period used.

## Propose a change

1. Fork this repository and clone your fork.
2. Create a branch for your change.
3. Make focused changes and update documentation when needed.
4. Check the script with `bash -n simple-interest.sh` and run the calculator with sample inputs.
5. Commit and push your branch.
6. Open a pull request explaining the change and how you verified it.

Please follow the Code of Conduct in `CODE_OF_CONDUCT.md`. Contributions are licensed under the project's Apache License 2.0.
